# Luvbird brand · v1

회사: **Luvbird** / 첫 제품: **DearBird**. 공개 표기는 **DearBird by Luvbird**입니다.

## 우리가 만드는 경험
DearBird는 메신저가 아닙니다. 국가·언어·관심사·교류 목적으로 한 사람을 찾고, 하루에 대한 사진과 편지를 보냅니다. 편지는 약 24시간 동안 이동하고, 답장은 상대의 속도로 다시 이동합니다. 좋아요, 팔로워, 읽음 표시는 없습니다. 프로필은 도시만 보여 줍니다. 실물 우편은 다음 이야기이며 지금 쓸 수 없습니다.

## 마크
새의 실루엣은 여정, 하트 모양 날개는 마음, 작은 봉투는 개인적인 이야기를 뜻한다. 직접 작성한 벡터 원본으로 앱 UI·아이콘·스플래시·지도에 같은 형태를 사용한다. 화면에 보이는 회사명은 Luvbird로 표기한다. 번들 ID, 세션 키, 데이터베이스 파일명에 쓰는 `luvbird`는 식별자이며 표시 이름이 아니다.

## 색상
| 역할 | 색상 |
|---|---|
| 잉크 / 제목·본문 | #24464A |
| 편지지 / 배경 | #F7F5EE |

| 봉투 / 표면 | #FFFEFA |

작은 본문은 잉크색을 사용한다. 코랄은 장식과 제한된 강조에 사용하며 색상만으로 상태를 구분하지 않는다. 로고 주변에는 새 머리 높이 이상의 여백을 남긴다. 비율을 늘이거나 그림자를 추가하지 않는다.

## 문구
- 한국어: 편지 한 통만큼, 조금 더 가까이.
- English: A little closer, one letter at a time.
- 日本語: 手紙を一通、心を少し近くに。

따뜻하고 짧게 쓴다. 답장·안전·궁합을 보장하지 않는다. 마감 압박, 읽씹 유도, 불안감을 이용한 구매 유도는 쓰지 않는다. 운영 중인 기능과 준비 중인 기능을 구분한다.

## 파일
`mobile/src/brandMark.ts`는 앱과 내보내기용 원본이다. `node scripts/brand-assets.mjs`로 SVG·PNG·아이콘을 재생성한다. 브랜드 배포 묶음에는 투명 배경 SVG/PNG 로고와 심볼, 앱 아이콘, 이 문서를 포함한다. 로고 글자는 시스템 sans-serif fallback을 사용하므로 SVG를 다른 환경에서 열면 서체가 달라질 수 있다. 상표·명칭 사용 가능성은 아직 확인되지 않았다.
