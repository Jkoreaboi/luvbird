# 스토어 등록 초안 — 아직 제출하지 않음

앱 이름: DearBird
회사/브랜드: luvbird
짧은 소개: 24시간의 설렘을 보내는 사진 펜팔
English: A little closer, one letter at a time.

## 소개

세계 어딘가의 누군가에게, 오늘의 작은 이야기를 보내세요.

DearBird는 사진과 편지로 마음을 나누는 펜팔 앱입니다. 관심사가 맞는 사람의 프로필을 살펴보고, 편지에 사진을 담아 보내세요. 당신의 비둘기가 세계 지도를 가로질러 24시간 뒤 편지를 전합니다.

- 국가와 관심사로 새로운 펜팔 찾기
- 사진 최대 3장과 함께 보내는 편지
- 월드맵 위에서 확인하는 가상 비둘기 여정
- 24시간 뒤 열리는 편지함
- 읽음 표시 없이 천천히 이어가는 대화

편지는 발송 후 24시간, 답장에도 추가로 24시간이 걸립니다. 실제 배송이 아닌 가상 여정이며 상대의 답장을 보장하지 않습니다. 만 18세 이상을 위한 서비스입니다.

## 제출 전 필요한 실제 값

- 법적 운영 주체명과 담당 연락처
- Support URL / Privacy Policy URL
- Apple/Google 계정 소유자와 확정된 앱 ID
- 최종 연령·콘텐츠 등급 설문, 데이터 수집/이용/제3자 처리 내역
- 실제 기기별 스크린샷과 검토용 계정

이 프로젝트의 화면 캡처는 개발 검토용 브라우저 렌더링이며, 스토어용 실제 기기별 검증 캡처로 대체해야 합니다.
